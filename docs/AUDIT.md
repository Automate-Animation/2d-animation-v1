## 4. Data model
Flow: Gentle JSON `{transcript, words[{word, alignedWord, case, start, end, phones[{phone,duration}]}]}` → mutated in memory by `update_values` ×8 (utils.py:65-67; adds `head_direction, eyes_direction, character, emotion, body_action, intensity, zoom, screen_mode` per word) → `add_phonemes` (add_phonemes.py:53-72; adds `phonemes, init_frame, final_frame, diff, phonemes_frame` + top-level `FRAME_PER_SECOUND, AUDO_END_TIME, TOTAL_VIDEO_FRAMES, MODE`) → `update_assets` (adds `emotion_name, character_name, background_name, body_name, phonemes_frame_details`) → `video_frames_info` writes `video_frames_info.csv` (15 columns, one row per frame) → only then `output_test.json` is dumped (core.py:62-64) → `frame_generator.py` reads the CSV, writes `video_frames/<key>.png` and `frameCreationInfo.json {key_counter:{key:n}, frame_key:{row_index:key}}` → `frame_to_video.py` reads `frameCreationInfo.json` only.
- **Duplicated**: `emotion`/`emotion_name`, `body_action`/`body_name`, `screen_mode`/`background_name`, `phonemes_frame` vs `phonemes_frame_details` (same counts plus `emotion`, `mouth_name`); CSV columns `Frame, Word, Start_Time, End_Time, Phoneme` are written but never read (frame_generator.py:35-44 reads 10 of 15); `frame_key` duplicates CSV row order.
- **Lossy**: intensity is folded into `emotion_name` (`_2` suffix); word boundaries and Gentle `phones` durations vanish at the CSV; the PNG key is a separator-less concatenation (frame_generator.py:45-56), e.g. `character_1happy_2explainLhappy_2_Lgreensadth_s1`, which cannot be parsed back into attributes, so `frameCreationInfo.json` is not reversible.
- **Where "each frame is controllable" holds**: editing `Character, Emotion, Body, Head_Direction, Eyes_Direction, Background, Mouth_Emotion, Mouth_Name, Zoom` in the CSV and rerunning `create_animation.py --skip-core` changes output.
- **Where it breaks**: `output_test.json` is never read (core.py:66-71 commented out) so edits there do nothing; any run of `core.py` rewrites the CSV with mode `"w"` (frame_info_generator.py:32), discarding hand edits; `Blink` is ignored (always true, §3); `Eyes_Direction` must equal `<Emotion>_<L|M|R>` or `02/03/04` or the file is not found; `Frame/Word/Start_Time/End_Time/Phoneme` edits are inert; timing is only row count, so a frame cannot be re-timed without adding/removing rows; cached PNGs mean `metadata.json` edits have no effect until `video_frames/*.png` are deleted (frame_generator.py:60-66); the randomly chosen asset file is recorded nowhere.
